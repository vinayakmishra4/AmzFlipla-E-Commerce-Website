## ✨ About The Project

**AmzFlipla** is a front-end e-commerce website designed to provide users with a smooth and enjoyable online shopping experience.

Inspired by popular shopping platforms like Amazon and Flipkart, this project combines an attractive user interface with interactive features using HTML, CSS and JavaScript.

---

## 🚀 Features

| Feature | Description |
|---|---|
| 🏠 Modern Homepage | Attractive homepage design |
| 🔍 Product Search | Search products by name |
| 🛒 Shopping Cart | Add products with cart counter |
| 🏷️ Categories | Explore shopping categories |
| 🔥 Special Deals | Promotional offers |
| 📱 Responsive UI | Mobile, tablet and desktop support |

## 💻 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/vinayakmishra4/AmzFlipla-E-Commerce-Website.git
```

**2. Open the project folder**

```bash
cd AmzFlipla-E-Commerce-Website
```

**3. Run the website**

Open `index.html` in your browser.

That's it! 🎉 Start exploring AmzFlipla.
